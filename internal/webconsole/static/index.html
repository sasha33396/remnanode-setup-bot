Замена IP leastload

Выберите ноды со скрытыми Host. Полный режим проверяет и при необходимости меняет сеть сервера. Режим без SSH меняет только Remnawave, DNS и основной IP в боте.

Сохранённые операции

Настройки сети

Проверка читает настройки по SSH. Адреса, firewall и службы не изменяются. Для legacy-нод без доступа бота будет показан пропуск.

LEGACY SSH

Подключение

Пароль не записывается в базу и удаляется из памяти сервера сразу после попытки подключения.

НОВАЯ НОДА

Добавить ноду

Типовая установка с выбранным Host, deploy-key, firewall и блокировкой порта 25.

REMNAWAVE 2.7.4 / 2.8.1

Создать Host из профиля и добавить ноду

Создаёт обычный видимый Host на выбранном inbound существующего Config Profile, затем запускает типовую установку ноды с firewall и Mail Guard.

Если Host уже существует с тем же доменом, профилем и inbound, он будет переиспользован. Конфликтующие настройки не перезаписываются.

СОБСТВЕННЫЙ HOST

Добавить балансировщик

Создаёт отдельный Host, Config Profile и inbound. Такая нода не обязана входить в общую DNS-балансировку.
